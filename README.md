# さこうクリエーションラボ 2027 サイト公開候補版（Design v5）

紹介者・紹介された方・検索から来た方のための静的サイト。GitHub Pagesを想定した相対パス構成。

## 構成
- index.html: トップ（入口に絞る／主な活動／相談の入口）
- care.html: メニューと料金（個別ケア・開催日限定ケア・活元運動と愉気の講座）、エリア
- noguchi.html: 野口整体・活元運動・愉気
- about.html: プロフィール（プロフィール表を追加）
- guide.html: ご利用の流れ（STEP表示）、FAQ、紹介者向け
- css/style.css: 共通CSS（v1〜v4の上書きを1本に整理）
- js/site.js: スマホ用メニューの開閉のみ

## 公開手順の概略
